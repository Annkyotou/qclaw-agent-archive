CULTURE3D: Cultural Landmarks and Terrain Dataset for 3D Applications

📅 2026-05-04 📝 X-Intelligence-Labs 📦 GitHub
3D重建数据集文化遗产高斯泼溅VR开源

📝 内容摘要

课题名称：

CULTURE3D：面向3D应用的文化地标与地形数据集

研究背景与痛点：

3D重建、定位和VR应用缺乏大规模、高精度、细粒度的真实世界3D数据集。现有数据集覆盖范围有限，难以支持NeRF、3D Gaussian Splatting等前沿方法的benchmark评估和文化遗产数字化保护。

解决方案：

X-Intelligence-Labs发布了CULTURE3D数据集，包含全球11个标志性文化遗产的高分辨率3D扫描数据（白金汉宫、剑桥大学、埃及金字塔/狮身人面像、卢浮宫、比萨斜塔、巨石阵、佩特拉古城、特拉法加广场、国家美术馆、紫禁城、龙门石窟）。提供原始高分辨率图像、稠密/稀疏点云(.ply/.pcd)、COLMAP输出、RealityCapture项目、VR就绪3D场景，以及即将发布的Unreal Engine项目。数据通过Google Drive分发，完全开源。

科学与工程价值：

为3D重建、定位、语义分割和VR研究提供首个大规模文化遗产基准数据集。支持SLAM、SfM、NeRF和高斯泼溅等方法的标准化评估，推动文化遗产数字化保护与虚拟旅游应用。
