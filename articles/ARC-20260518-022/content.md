# ARC-20260518-022 核心内容摘要

## 课题名称
**一张遥感图像，直接生成整条街的3D实景！ICLR 2026创新模型（Sat3DGen）**

## 研究背景与痛点
城市三维重建传统依赖大量实地采集与漫长建模，高空图像生成3D街景长期面临两大困境：
1. 先建模后贴材质的方法建筑规整但缺失道路/植被等要素，实用性低
2. 端到端生成方法内容全但几何严重失准（屋顶歪扭、墙面撕裂、悬浮碎片、地面坑洼）
根本原因在于视角差大（俯视→平视）、监督信息稀缺、边缘畸变严重

## 解决方案
武汉大学、蚂蚁集团、浙江大学联合提出 **Sat3DGen**，单张遥感图直接生成高精度3D街景。四大核心模块：
1. **重力密度约束**：低处密度高、高处稀疏的物理先验，消除悬浮伪影
2. **高空视图深度约束**：单目深度信号引导屋顶平整，无需真实深度标注
3. **透视视图训练**：从全景切出大量透视视角，模拟人眼/车载相机视角
4. **天空分离优化**：天空建模在球面，保证全景与透视视角一致

## 科学与工程价值
几何精度 RMSE 从 6.76m 降至 **5.20m**，FID 从 40+ 降至 **19.2**（近乎减半）。建筑墙面笔直、屋顶平整、斑马线绿化带清晰。模型可导出完整3D网格，直接用于数字孪生、自动驾驶仿真、智慧城市等平台，为从遥感图像到大规模三维数字世界的低成本构建铺平道路。
